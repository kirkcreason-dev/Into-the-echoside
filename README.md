# Into the Echoside — Digital Game Table

A development edition with original scanned card art, a server-authoritative rules engine, a guided tutorial, solo AI and private online rooms for 2–4 players.

## Run

Use Node.js 22 or newer. Run `npm install`, `npx wrangler d1 migrations apply echoside-matches --local`, then `npm run dev`. Production Worker output is generated by `npm run build`; it requires a D1 binding named `DB` and an assets binding named `ASSETS`.

Room codes invite other players. Sessions use an HttpOnly cookie; the server saves game state and choices in D1. Reconnect from the same browser and game URL. Hidden hands and deck order are removed from other players’ responses. Optimistic revisions reject stale or simultaneous conflicting actions. No payments, fake matchmaking, or simulated online opponents are used in multiplayer.

## Guided first game

Choose **Learn to play · guided game** on the home screen, or **Start tutorial** under How to play. The guide creates a separate base-game practice table with a prepared opening hand and Gallery. Eight lessons cover Karma, crews, Unity, recruitment, Fiends, ending a turn, stomps, and continuing the match. Highlighted table controls and the guide use the same server-validated actions.

Progress and unfinished choices are saved with the room. Leaving the guide keeps the match; if a choice is unfinished, its uncommitted move is restored before free play resumes. Complete the tutorial to continue against the Void with your current deck.

## Content and fidelity

196 distinct card variants were transcribed and mapped to scans from the public Tabletop Simulator port by BladesDark. Five promos are viewable in the library but excluded from match decks. The base main deck counts match the published 107-card inventory. Costs, points, shields and expansion emblems were checked against the scans. See SOURCES.md.

**This is not a certified official release and is not rules-perfect.** The available source lacks Gambits and both complete rulebooks. Oracle setup, precise Fast/Mirror timing, ties, and uncommon interactions require publisher verification. The UI labels the Oracle card set as a development interpretation. No publishing license is asserted.

Known limitations: no Gambit draft, no 2v2 team rules, no account-based cross-device recovery, no disconnect turn timer. Sessions resume only while the browser cookie remains available. AI advances while a participant has the game open. In the present engine, Fast and Mirror play is offered at discrete action windows rather than a verified expansion priority procedure.

## Validation

`npm test` checks printed base component counts, invalid actions, private state projections, deterministic choice replay, every implemented card effect, and 30 complete two-, three-, and four-player AI games. The simulated games preserve unique physical cards and finish with equal turn counts. Local API integration checks used independent cookie sessions for host and guest: create/join/start, authorization, hidden hands, stale revision rejection, synchronized moves, and reconnect.

Tutorial checks cover prepared setup, legal lesson progression, deterministic choices, card conservation, leaving guidance, and isolation from normal multiplayer and expansion games.

## GitHub Pages

The playable GitHub edition is at https://kirkcreason-dev.github.io/Into-the-echoside/ . The root `index.html`, `.nojekyll`, and `public/pages-bundle.js` are ready-to-serve files for the repository’s existing **main / (root)** Pages setting. After changing the game, run `npm run build:pages` and commit those generated files together with the source. `pages-dist/` is a standalone static export for other static hosts.

The GitHub edition runs the same rules engine entirely in the browser. Solo matches and tutorials save on the device in IndexedDB. Online rooms use encrypted WebRTC data connections through PeerJS’s public signaling service. The host validates moves, saves the match, and sends each guest a view with other hands and deck order removed. Keep the host’s tab open; the host’s browser must return for a disconnected match to resume. Rejoin from the same browser to keep your seat. The host holds the full match state, so play with someone you trust. No dedicated TURN relay is configured; restrictive networks may prevent a direct connection. This differs from the separately hosted Worker/D1 edition described above.

GitHub Pages validation includes room permissions, stale moves, hidden guest hands, choice replay, tutorial persistence, untrusted remote-view validation, and a two-browser multiplayer walkthrough with the Oracle card set. Generated Pages files do not require a ChatGPT sign-in.
