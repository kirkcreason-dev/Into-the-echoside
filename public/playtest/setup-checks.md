# Oracle setup comparison

Kit 0.3.1. Run these checks at two, three and four seats using the physical Oracle booklet. They supplement the eight fixed midgame positions; they are not completed playtest results.

## Juggalo Army

1. Create an online table with **Base + Oracle cards**, turn **Include Gambits** off, and select **Juggalo Army** under Optional variants. Seat everyone before starting.
2. Each physical player takes the normal ten Starter cards. Match the digital player's choice of three cards to remove. Set these aside outside the game, not in the Abyss or a discard pile.
3. Use the draft order shown in the digital match journal for this controlled comparison. The program rolls a separate d12 contest for first chooser and repeats tied high rolls. Record those rolls/order; do not compare two unrelated random outcomes.
4. Spread all 30 physical Juggalos face up. Follow the same choices: one Juggalo per player, clockwise, for three rounds. Check that a previously selected physical card is unavailable to later choosers. Match the printed Crew as well as the title.
5. Before shuffling, each personal deck must contain seven remaining Starters and three chosen Juggalos. The shared supply must contain 24, 21 or 18 Juggalos at two, three or four seats. Twelve or fewer removed Starters remain outside the game.
6. Shuffle the remaining Juggalo Deck and each personal deck, then draw the opening hands. The digital game determines the first turn separately. Do not expect independently shuffled hand identities or first-player rolls to match. To compare later turns, use one of the fixed positions in the kit.
7. Repeat with Gambits enabled. Both setup choices must complete before the first turn. Test a reload during starter removal and again during Juggalo selection; choices already confirmed must remain confirmed. Test host backup restoration at either point.

Record any disagreement with the printed setup order, die procedure, removed-card destination or supply. Include the relevant rulebook page. The recovered original Juggalo Army paragraph establishes the replacement and round-robin selection rules; the complete booklet still needs to be checked for cross-variant ordering.

## Gambits are optional

- With **Include Gambits** off, there must be no Gambit draft, hand or reaction card; Oracle Main, Flavor, Epic, Tarot and Juggalo cards remain available.
- With it on, the current implementation deals ten private choices and allows up to three purchase points. Check the full printed setup separately at every player count; the narrated source explicitly demonstrates two players.
- A pre-0.3.1 saved Oracle lobby keeps its previous Gambit-enabled behavior when restored.
